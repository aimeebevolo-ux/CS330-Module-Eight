How do I approach designing software?

When I started this project, I focused on figuring out how to recreate my computer desk using simple 3D shapes. I looked at the objects in my reference picture and decided which shapes would work best for each one. I learned that planning the placement, size, and appearance of objects makes a difference in how the final scene turns out. I also learned to keep things simple instead of making the code more complicated than it needed to be. In future projects, I can use the same approach by breaking a larger problem into smaller parts and planning how those parts will work together.

How do I approach developing programs?

Throughout this project, I learned how to work with textures, lighting, transformations, and camera controls in OpenGL. One of the biggest things I learned was the importance of testing changes as I worked. For example, changing the lighting sometimes made my desk too dark, so I had to adjust the settings and test the scene again. I also learned to reuse basic shapes and functions instead of creating everything from scratch. As I moved through the project milestones, I became more comfortable making changes, finding problems, and figuring out how different parts of the code affected the final result.

How can computer science help me reach my goals?

As a computer science student, this project gave me experience with a different side of programming. I had worked on projects involving databases and other programming concepts, but creating a 3D scene helped me understand how code can be used to build something visual and interactive. I learned how shapes, textures, lighting, and camera movement work together to create a scene. These skills can help me in future courses by giving me more experience with problem-solving and debugging. They can also be useful in my future career because they taught me how to work through a project, test my ideas, and improve the results as I go.
